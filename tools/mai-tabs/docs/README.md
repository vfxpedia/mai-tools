## 여기에 없는 것

- **BM (가격 · 원가 · 사업 계산) 은 이 공개 저장소에 두지 않는다.** 비공개 자리에 따로 있고, 위치는 vfxpedia/mai-os#57 에 적혀 있다. 04 는 그 자리에 있고, 이 표에는 상태만 적는다.
- 개인 자료 (실제 탭 목록, 계정, 기기 이름이 붙은 기록) 는 넣지 않는다. 실측 숫자는 기기 이름 없이 적는다.

## 이어 가는 법

1. 이 표에서 상태가 「아직」인 첫 문서를 찾는다
2. 앞 문서들을 읽고, 정해진 것은 다시 묻지 않는다. 정해진 것의 출처는 각 문서의 「정해진 것」 절
3. 문서마다 머리 다섯 줄 (분류 · 작성 · 근거 · 요지 · 상태) 부터 쓴다
4. 다 쓰면 이 표를 고치고, 같은 커밋에 넣는다
