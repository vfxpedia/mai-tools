# mai-watch product completion

Spec: 팀장이 승인한 대화의 다섯 항목과 CPU 표시 변경. 기존 Python stdlib + psutil, 정적 JS를 유지한다. 별도 데이터베이스나 외부 서비스를 넣지 않는다.

## 설계와 선택

전체 재배치 대신 기존 격자와 높이를 유지한다. 실측 코어 영역 202.5/172px를 기준으로 100/86px로 고정하고 상위 CPU 3개를 넣는다. CPU는 PID+생성시각별 누적 user/system CPU 시간의 단조시계 차분으로 측정한다. 한 코어=100%, 최초/권한 거부/재사용/역행은 unknown.

진단은 현재 측정의 가용성·이유·다음 점검만 설명한다. 안전한 진단 내보내기는 서버의 명시적 숫자/상태 allowlist만 사용하고 프로세스명, 경로, 세션 제목, 명령행, 로그, 환경변수를 배제한다.

경고는 기존 단일 판정 목록에 관측 시작/최근시각/관측기간/다음 점검을 덧붙인다. unknown·표본 공백은 해소 증거가 아니다. 사건 최대 256개, 24시간 보관, 메모리 전용. 재시작시 초기화임을 표시한다. 원시 표본은 기존 기본 10분과 최대 개수 상한을 유지한다. 1/5/10분 선택은 실제 보유 범위 안에서만 제공한다.

보기 설정은 이 브라우저 localStorage에만 저장한다. 고정 격자는 바꾸지 않고 자원/AI 강조와 보조 표 기본 펼침을 선택한다. 경고·GPU·한도는 숨기지 않는다. 설정 저장 거부시 화면은 계속 작동한다.
