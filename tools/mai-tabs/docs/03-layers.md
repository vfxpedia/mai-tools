# 03 구성 층

## 1. 한눈에

| 층 | 하는 일 | 사는 곳 | ORBIT | NEBULA | UNIVERSE |
|---|---|---|---|---|---|
| 모으기 | 열린 탭 · 창 · 탭 묶음, 방문 기록, 북마크, 붙인 생각, 음성, 「공유하기」로 온 것 | 브라우저 확장, 휴대폰 화면 | 열린 탭 · 창 · 묶음 | 나머지 전부 | (NEBULA 에서 받음) |
| 기억 | 페이지 · 방문 · 관계 · 카드 상태 · 작업 공간 · 휴지통 | 각 기기 (확장 저장소와 동반 앱의 파일), 사용자가 고른 동기화 자리 | 페이지 · 작업 공간 · 휴지통 | 방문 · 관계 · 생각 · 카드 상태 | 별 · 별자리 · 공개 범위 |
| 이해 | 분류, 중복, 의도 짐작, 관계 추론, 요약, 메모리 실측 | 확장 (규칙), 동반 앱 (실측 · PC 안 모델), 모델 연결부 | 분류 · 중복 · 의도 · 실측 | 관계 · 요약 · 주간 보고 | 같은 별 찾기 |

| 잇기 | 에이전트 창구, 동기화, 볼트로 인사이트 보내기, 기기 사이 명령 | 동반 앱, 동기화 자리 | 기기 사이 명령 | 에이전트 창구 · 볼트 | 다른 사람의 우주 |

원칙: **아래 층은 위 층 없이 돌고, 단계는 다음 단계 없이 돈다.** ORBIT 만 깔아도 모으기 · 기억 · 이해 · 보여 주기가 다 된다. NEBULA 를 켜면 같은 층에 일이 더해진다.

## 2. 구성 요소

| 요소 | 무엇 | 없을 때 |
|---|---|---|
| 확장 | 브라우저 안에서 모으고, 탭을 열고 · 재우고 · 닫고 · 옮기고, 화면을 그린다 | 제품이 없다 (필수) |
| 동반 앱 | PC 에서 메모리를 실제로 재고, PC 안 모델을 돌리고, 에이전트 창구와 휴대폰 화면을 연다 | 메모리 숫자 대신 탭 수만, 에이전트 창구 없음, 휴대폰은 동기화 자리를 통해서만 |
| 동기화 자리 | Google Drive (기본) · 내 서버 · 구독 중 하나 | 기기마다 따로 논다 |
| 휴대폰 화면 | 동반 앱이나 내 서버가 띄우는 웹 화면, 「공유하기」 받기 | 휴대폰에서 못 본다 |
| 모델 연결부 | 요약 · 분류 · 관계 추론을 맡길 곳을 고른다 | 규칙만 쓴다 (무료판 기본) |

지금 2 판과 비교하면: 2 판의 「서버」 (`mai_tabs/server.py`) 가 동반 앱의 씨앗이다. 2 판은 화면도 서버가 띄우지만, 다음 판에서는 화면의 정문을 확장 (사이드 패널) 으로 옮기고, 서버는 실측 · 모델 · 에이전트 창구 · 휴대폰 화면을 맡는다.

## 3. 자료의 흐름

1. 확장이 탭 · 창 · 묶음의 변화를 받는다 (탭이 열림 · 바뀜 · 닫힘 · 옮겨짐). 2 판처럼 30 초마다 전체를 다시 보내지 않고, 변할 때 보낸다
2. 주소를 깨끗하게 한다: 비밀이 든 파라미터를 빼고, 거르는 사이트 (로그인 · 메일 · 은행 등) 는 아예 남기지 않는다 (2 판의 규칙을 이어 씀)
3. 기억 층에 쓴다: 페이지 (한 페이지는 하나), 방문 (언제 · 어디서 넘어왔나), 관계
4. 이해 층이 붙는다: 분류 · 중복 · 의도는 바로, 관계 추론 · 요약은 한가할 때
5. 보여 주기 층이 읽는다. 제안은 이해 층이 만들고, 사용자가 누를 때만 확장이 동작한다
6. 동기화가 켜져 있으면 바뀐 부분만 동기화 자리로 보낸다 (구독이면 기기에서 암호화한 뒤)

## 4. 관계를 무엇으로 아나

graphify 처럼 관계마다 「관찰」과 「추론」을 나눠 적는다. 관찰은 사실이고, 추론은 틀릴 수 있어 사용자가 고칠 수 있다.

| 관계 | 근거 | 종류 |
|---|---|---|
| 이 탭에서 저 탭이 열렸다 | 탭이 열린 출처 탭 (확장 API 의 `openerTabId`) | 관찰 |
| 이 방문에서 저 방문으로 넘어왔다 | 방문 기록의 「넘어온 방문」 (`referringVisitId`, 확인 필요) | 관찰 |
| 같은 창 · 같은 묶음에 함께 있었다 | 창과 묶음, 시각 | 관찰 |
| 연달아 봤다 | 마지막으로 본 시각 | 관찰 |
| 같은 내 프로젝트의 자료다 | 저장소 · 이슈 주소, 사용자가 붙인 묶음 | 관찰 |
| 같은 주제다 | 제목 · 주소 (무료는 규칙과 PC 안 모델, 유료는 모델 연결부) | 추론 |
| 이래서 열었겠다 (의도) | 위 관계와 행동 (머문 시간, 다시 본 횟수) | 추론 |

관찰한 관계는 지나간 것을 되살릴 수 없다. 그래서 신호 수집은 첫 단계 (A) 부터 한다.

## 5. 다섯 가지 중립을 지키는 자리

| 중립 | 연결부 | 처음에 붙일 것 | 나중에 |
|---|---|---|---|
| 모델 | 「요약 · 분류 · 관계 추론」을 받는 한 겹. 입력은 제목 · 주소 (본문은 사용자가 고른 탭만), 출력은 정해진 모양 | 규칙 (무료), PC 안 모델 (OpenAI 호환 로컬 서버), Haiku (유료 기본) | OpenAI · Google 등, 사용자 자기 키 |
| 브라우저 | 확장 안의 「브라우저 어댑터」. 탭 · 창 · 묶음 · 재우기 · 방문 기록 · 북마크 | Chrome | 같은 확장으로 Edge · Brave · Whale, 나중에 Firefox · Safari |
| 기기 | 동기화 어댑터 | Google Drive (기본), 내 서버 (로컬 폴더 + 사설망 안내) | 구독 (종단간 암호화) |
| 에이전트 | 동반 앱이 여는 MCP 도구 (찾기 · 최근 관심 · 페이지 하나 보기) | 제품 담당자 본인의 에이전트 세션 | 사용자가 허락한 어느 에이전트든 |
| 출처 | 「받기」 한 겹. 무엇이 왔든 페이지 · 생각으로 바꾼다 | 브라우저 탭 | 휴대폰 「공유하기」, SNS 에서 본 것 |

## 6. 지켜야 할 경계

- **확장이 아니면 탭을 건드리지 않는다.** 동반 앱 · 휴대폰 · 에이전트는 「해 달라」는 요청만 보낸다. 실제 동작은 확장이 그 순간의 탭을 다시 확인한 뒤에 한다 (2 판에서 검증한 방식)
- **에이전트 창구는 읽기 전용으로 시작한다.** 에이전트가 탭을 닫거나 기록을 지우는 것은 나중에, 사용자 확인을 거쳐서만
- **방문 기록과 붙인 생각은 기본으로 기기 밖에 나가지 않는다.** 동기화를 켤 때 무엇이 나가는지 따로 보인다
- **ORBIT 은 NEBULA 없이 완결된다.** NEBULA 를 끄면 방문 기록 · 관계 · 생각은 남지 않고, ORBIT 의 기능은 그대로다

## 7. 정해진 것

- 다섯 층과 단계별 경계 (제품 담당자 10/25 승인)
- 동반 앱이 메모리를 실측한다, 추정만 보이지 않는다
- 다섯 가지 중립, 유료 요약 기본은 지금 Haiku
- 동기화 세 갈래, 구독은 종단간 암호화
- 에이전트 창구는 제품 담당자 본인의 세션부터
