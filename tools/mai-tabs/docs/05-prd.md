## 3. 카드 규칙 (F-21 · F-26)

- **어떤 페이지가 카드가 되나**: 열린 탭에서 사라진 (모든 탭이 닫힌) 페이지 중, 읽으려는 의도가 보이는 것 (나중에 · 호기심, 논문 · 글, 생각을 붙인 것, 오래 머문 것, F-21 로 넘긴 것). 검색 결과 화면 · 로그인 뒤 첫 화면 · 지켜보기 페이지는 카드가 되지 않는다. 계속 열려 있는 탭은 카드가 아니라 4 절의 제안 대상이다
- **일정**: 그 페이지의 마지막 탭이 닫힌 때부터 2 일 · 1 주 · 2 주 · 1 달. 간격은 닫힌 때 기준으로 고정이고 답이 늦어도 미루지 않는다. 카드 전에 다시 열리면 일정을 멈추고, 다시 닫히면 처음부터 다시 잰다
- **넘기기**: 오른쪽 = 기억 (keep), 왼쪽 = 아니
- **다시 방문**: 카드에서 열거나 다른 경로로 다시 열어 30 초 이상 머물면 오른쪽으로 친다 (30 초는 가정, 베타에서 조정). 그보다 짧으면 치지 않는다
- **기억이 되는 조건**: 오른쪽 한 번. 별은 더 묻지 않는다 (별을 다시 정리하는 일은 E 단계)
- **답 없음**: 다음 간격이 오기 전에 답하지 않은 카드는 「답 없음」이다. 답 없음은 왼쪽 연속을 끊지도 잇지도 않는다 (센 데서 뺀다). 따로 다시 띄우지 않고 다음 간격 카드가 제때 나온다
- **블랙홀이 되는 조건**: 답한 카드만 세어 왼쪽이 세 번 연속. 예: 왼쪽 · 답 없음 · 왼쪽 · 왼쪽 은 블랙홀
- **네 장이 끝나도 정해지지 않으면**: 별도 블랙홀도 아니면 「대기」로 두고 더 묻지 않는다
- **블랙홀**: 지우지 않는다. 찾기에는 흐리게 나온다. 블랙홀 페이지를 다시 열어 30 초 이상 머물면 별로 되살린다. 1 년 뒤 카드 한 장으로 「1 년 전 관심, 다시 볼까요?」
- **휴지통과의 관계**: 카드 일정은 휴지통과 따로 간다. 휴지통에서 빠져도 카드는 그대로
- **넘치지 않게**: 하루 카드 상한 (기본 5 장), 사용자가 바꾼다. 분류별로 카드를 끌 수 있다

| 중복 정리 | 같은 페이지 둘 이상 | 「같은 논문이 3 번 열려 있습니다」 |
| 지난 검색 결과 | 검색 결과 화면이고, 거기서 연 페이지가 있음 | 「이 검색에서 이미 4 곳을 열어 보셨습니다」 |
| 끝난 일 | 병합 · 닫힘이 보이는 PR · 이슈 페이지 | 「병합이 끝난 PR 5 개」 |
| 비교 정리 | 비교 중 의도의 묶음에서 하나를 오래 봄 | 「숙소 5 곳 중 한 곳을 오래 보셨습니다. 나머지를 보관할까요?」 |
| 작업 공간 만들기 | 같은 창의 탭이 한 주제로 모임 | 「이 창은 논문 7 편입니다. 『논문 묶음』 작업 공간으로 저장할까요?」 |
| 창 다시 배열 | 주제가 섞인 창이 셋 이상 | 「논문이 창 4 곳에 흩어져 있습니다」 |

모든 제안은 F-04 미리 보기를 거치고, 받아들이지 않은 제안은 같은 대상으로 하루 동안 다시 하지 않는다.

## 5. 화면 흐름

1. 설치 → 첫 실행 (F-01): 숫자 하나 · 단추 하나. 방문 기록은 첫 화면에서 묻지 않고, NEBULA 를 처음 켤 때 묻는다 (F-11)
2. 사이드 패널 홈 (F-02): 지금 상태 · 줄일 수 있는 양 · 제안 셋 · 오늘의 카드
3. 보드 (F-03): 창별 칸 → 칸을 누르면 그 창의 탭 · 묶음
4. 일괄 동작 → 미리 보기 (F-04) → 실행 → 결과 (F-05) → 되살리기
5. 찾기 (F-22): 단축키 → 입력 → 결과 (열린 탭 · 보관함 · 블랙홀 순)
6. 카드 (F-26): 홈의 「오늘의 카드」 또는 알림 → 넘기기
7. 휴대폰 (F-42): 홈 · 보드 · 찾기 · 카드의 같은 화면, PC 로 보내기

## 6. 하지 않을 것

- 사용자 몰래 탭을 닫거나 옮기기 (자동 규칙도 「재우기」까지만, 닫기는 사용자가)
- 방문 기록을 사용자가 고르지 않은 곳으로 보내기
- 페이지 본문을 묻지 않고 모델에 보내기
- 광고, 기록 판매

## 8. 정해진 것

- 카드 간격과 좌우 방향 (제품 담당자 10/25)
- 자동 규칙은 재우기까지, 닫기는 사용자가 (01 의 원칙 3, 7a 의 하지 않을 것)
- 첫 실행에서 방문 기록을 묻지 않는다 (02 의 5 절: 처음 30 초에 좋은 것 하나)
