# 05 PRD

## 1. 목표와 지표

| 목표 | 지표 | 첫 목표값 (베타, 초안) |
|---|---|---|
| 믿고 맡긴다 | 정리 · 재우기 · 닫기를 되돌린 비율 | 10 % 아래 |
| 계속 쓴다 | 설치 1 주 뒤에도 쓰는 사람 (극단 · 많음 유형) | 60 % 이상 (02 의 7 절) |
| 다시 꺼내 본다 | 사람당 1 주에 보관함 · 찾기 · 카드에서 다시 연 페이지 | 3 개 이상 |

## 3. 카드 규칙 (F-21 · F-34)

- **어떤 페이지가 카드가 되나**: 닫혔거나 휴지통에 간 페이지 중, 읽으려는 의도가 보이는 것 (나중에 · 호기심, 논문 · 글, 생각을 붙인 것, 오래 머문 것). 검색 결과 화면 · 로그인 뒤 첫 화면 · 지켜보기 페이지는 카드가 되지 않는다
- **언제**: 그 페이지가 닫힌 뒤 2 일 · 1 주 · 2 주 · 1 달
- **넘기기**: 오른쪽 = 기억 (keep), 왼쪽 = 아니, 위 = 지금 열기. 카드에서 페이지를 열거나, 다른 경로로 다시 방문해도 오른쪽으로 친다
- **기억이 되는 조건**: 오른쪽 한 번이면 별 (기억) 이 된다. 별은 더 묻지 않는다 (별을 다시 정리하는 일은 E 단계에서)
- **블랙홀이 되는 조건**: 왼쪽이 세 번 연속. 오른쪽이 한 번이라도 끼면 별이 되므로 「섞인 경우」는 없다. 네 번째 카드 (1 달) 까지 왼쪽이 둘 이하이고 오른쪽이 없으면 「대기」로 남기고 더 묻지 않는다
- **답하지 않으면**: 그 카드는 다음 간격에 한 번만 다시 나온다. 네 번 다 답이 없으면 「대기」
- **블랙홀**: 지우지 않는다. 찾기에는 나오고 (흐리게), 1 년 뒤 카드 한 장으로 「1 년 전 관심, 다시 볼까요?」
- **넘치지 않게**: 하루 카드 상한 (기본 5 장), 사용자가 바꾼다. 분류별로 카드를 끌 수 있다

## 4. 제안 규칙 (F-31)

| 제안 | 조건 | 이유 문장 예 |
|---|---|---|
| 재우기 | N 시간 안 본 깨어 있는 탭 (지금 보는 탭 · 고정 · 소리 나는 탭 제외) | 「3 시간 안 본 탭 26 개입니다. 재우면 약 4 GB 줄어듭니다 (지난 실측 기준)」 |
| 중복 정리 | 같은 페이지 둘 이상 | 「같은 논문이 3 번 열려 있습니다」 |
| 지난 검색 결과 | 검색 결과 화면이고, 거기서 연 페이지가 있음 | 「이 검색에서 이미 4 곳을 열어 보셨습니다」 |
| 끝난 일 | 병합 · 닫힘이 보이는 PR · 이슈 페이지 | 「병합이 끝난 PR 5 개」 |
| 비교 정리 | 비교 중 의도의 묶음에서 하나를 오래 봄 | 「숙소 5 곳 중 한 곳을 오래 보셨습니다. 나머지를 보관할까요?」 |
| 작업 공간 만들기 | 같은 창의 탭이 한 주제로 모임 | 「이 창은 논문 7 편입니다. 『지형 보행』 작업 공간으로 저장할까요?」 |
| 창 다시 배열 | 주제가 섞인 창이 셋 이상 | 「논문이 창 4 곳에 흩어져 있습니다」 |

모든 제안은 F-04 미리 보기를 거치고, 받아들이지 않은 제안은 같은 대상으로 하루 동안 다시 하지 않는다.

## 5. 화면 흐름

1. 설치 → 첫 실행 (F-01): 숫자 하나 · 단추 하나 · 「방문 기록도 읽을까요?」는 나중에 (첫 화면에서 묻지 않는다)
2. 사이드 패널 홈 (F-02): 지금 상태 · 줄일 수 있는 양 · 제안 셋 · 오늘의 카드
3. 보드 (F-03): 창별 칸 → 칸을 누르면 그 창의 탭 · 묶음
4. 일괄 동작 → 미리 보기 (F-04) → 실행 → 결과 (F-05) → 되살리기
5. 찾기 (F-22): 단축키 → 입력 → 결과 (열린 탭 · 보관함 · 블랙홀 순)
6. 카드 (F-34): 홈의 「오늘의 카드」 또는 알림 → 넘기기
7. 휴대폰 (F-42): 홈 · 보드 · 찾기 · 카드의 같은 화면, PC 로 보내기

## 6. 하지 않을 것

- 사용자 몰래 탭을 닫거나 옮기기 (자동 규칙도 「재우기」까지만, 닫기는 사용자가)
- 방문 기록을 사용자가 고르지 않은 곳으로 보내기
- 페이지 본문을 묻지 않고 모델에 보내기
- 광고, 기록 판매

## 8. 정해진 것

- 카드 간격과 넘기는 방향 (제품 담당자 10/25)
- 자동 규칙은 재우기까지, 닫기는 사용자가 (01 의 원칙 3, 7a 의 하지 않을 것)
- 첫 실행에서 방문 기록을 묻지 않는다 (02 의 5 절: 처음 30 초에 좋은 것 하나)
