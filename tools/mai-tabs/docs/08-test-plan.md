# 08 재현 시험 계획

## 1. 원칙

1. **답을 아는 입력으로 먼저 시험한다.** 모든 시험 자료는 「무엇이 나와야 하는지」를 함께 적는다
2. **조용한 실패를 소리 나게.** 결과가 비었거나 일부만 됐는데 「통과」가 나오는 길을 두지 않는다. 시험 수가 0 이면 실패다
3. **시험이 진짜 재는지 망가뜨려 본다.** 안전장치 시험은 그 장치를 일부러 하나씩 빼고 시험이 실패하는지 본다 (2 판에서 다섯 장치로 한 방식). 판마다 반복한다
4. **사용자가 겪는 층에서 본다.** 단위 시험이 통과해도 실제 Chrome 에서 탭이 그렇게 됐는지 따로 본다
5. **한 줄로 다시 돌린다.** 모든 시험은 명령 하나로 돌고, 결과를 파일로 남긴다 (`common/run_all_tests.py` 에 붙임)

**가짜 브라우저는 Chrome 의 실제 버릇을 흉내 낸다.** 2 판에서 실제 Chrome 확인으로만 잡힌 버릇이 셋이었다. 다음 판의 가짜는 처음부터 이것들을 한다:
- 재운 탭은 새 탭 id 를 받는다
- 주소가 정해지기 전에 재우면 주소를 잃는다
- 재우기를 거절하면 결과 없이 끝난다

다음 판에서 더하는 버릇:
- 닫힘 이벤트는 주소를 주지 않는다 (07 의 2 절)
- 서비스 워커는 30 초 쉬면 멈추고 다시 뜬다 (타이머를 믿는 코드가 실패해야 한다)
- 탭 id 는 브라우저를 다시 켜면 바뀐다
